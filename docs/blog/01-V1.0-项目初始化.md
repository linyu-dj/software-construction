# V1.0 项目初始化：先让它跑起来，分层以后再说

> 软件构造综合实践 · 第 1 轮迭代
> 提交 `58f1b0a` · 标签 `v1.0` · 2026-11-12

这轮任务说简单也简单：建个项目，写个登录。但我把它当成"定规矩"的一轮，因为后面 19 次迭代都要在这个骨架上改，现在定歪了，之后每轮都得跟着还债。

## 一、这轮真正要定的三件事

任务书只写了"程序入口 + 固定账号 + 控制台登录"，验收也就三种结果。但有三样东西是后面躲不开的：

第一是包名。我用了 `campus`，因为题目是校园资源预约，以后 `campus.entity`、`campus.service`、`campus.dao` 都能直接挂在下面。如果 V1.0 图省事用默认包，等到 V1.2 建 `User` 实体的时候就得改一次包，等于白干一遍。

第二是入口。所有交互都从 `SystemMain.main()` 进，这个入口后面一直留着，只是它调用的东西会越来越复杂。

第三是"角色"这个概念。系统里天然有管理员和学生，权限完全不一样。V1.0 虽然只做登录，但登录完必须能说清楚"你是谁"，否则 V2.0 做资源管理的时候，菜单都分不出去。

## 二、代码写成什么样

账号直接写在主方法里：

```java
String adminUsername = "admin";
String adminPassword = "123456";
String studentUsername = "student";
String studentPassword = "123456";
```

判断也是挤在一个 if-else 里：

```java
if (username.equals(adminUsername) && password.equals(adminPassword)) {
    System.out.println("登录成功！欢迎您，管理员 " + username + "。");
    System.out.println("当前身份：ADMIN");
    loggedIn = true;
} else if (username.equals(studentUsername) && password.equals(studentPassword)) {
    ...
} else {
    System.out.println("登录失败：账号或密码错误，请重新输入。");
}
```

这里说一下为什么不写成"校验一个方法、打印一个方法、登录一个方法"。任务书里明确写了本阶段代码全部放在主类、不抽工具类，是故意让耦合留下来的。我一开始觉得这条要求有点别扭，后来想明白了：如果第一轮就分好层，那后面几轮就没有真实的改造动因，博客里写的"重构"全是自己给自己出的题。现在这段代码确实难扩展，V1.1 想加个注册功能就必须动它，这才像真实的迭代。

## 三、输入这块我做了个取舍

菜单选项、账号、密码三个输入，我全部用 `nextLine()` 读，读完 `.trim()`，没有用 `nextInt()`。

原因是控制台里 `nextInt()` 只吃掉数字，把回车留在缓冲区，紧接着的 `nextLine()` 会读到空串，人就会遇到"我刚输了账号，它怎么直接跳到密码了"这种莫名其妙的现象。代价是判断选项要写成 `"1".equals(choice)`，不是 `choice == 1`，这一点换来了整个交互里不可能出现输入被吞掉的情况。

## 四、踩的坑

**第一个坑：`javac: 找不到目录: out`**

第一次编译就报这个。我第一反应是路径写错了，检查了半天 `src\campus\SystemMain.java` 是对的。实际上 `-d out` 只指定输出目录，`javac` 不会帮你创建它。先 `mkdir out` 再编译就成了。这条已经写进 `run.bat` 里，现在直接跑脚本不会碰到。

**第二个坑：中文全变乱码**

源码文件是 UTF-8，但 Windows 上的 `javac` 默认按 GBK 读源码，编译出来的字符串本身就是错的，怎么调控制台都没用。三个地方都要对：编译加 `-encoding UTF-8`，运行加 `-Dfile.encoding=UTF-8`，批处理里再 `chcp 65001`。少一个就还是乱码。

**第三个坑：GitHub Pages 上的博客点进去 404**

博客首页明明写好了，点"阅读"却跳到 Unicorn（GitHub 的 404 页面）。原因是 Jekyll 会把 `01-V1.0-项目初始化.md` 渲染成 `.html`，但我索引里链接写的是 `.md`，那个文件在站点上根本不存在。把 `docs/index.md` 里的链接后缀全部改成 `.html` 就好了。这个坑以后每加一篇博客都会遇到，所以我在写索引的时候统一用 `.html`。

**另外一个跟代码无关的**：IDEA 第一次打开这个子文件夹时右下角弹了"未安装 Git"。查了一下其实是两件事叠在一起——IDEA 自己没配 Git 路径，而且它默认不信任新打开的目录，未信任状态下所有 Git 命令都被禁。系统里 Git 是好的，命令行提交推送都正常，所以这个问题不影响交付，只是 IDEA 那边要手动配一次路径、点一次信任。

## 五、跑出来的结果

用命令行喂输入跑了五组，都是实际输出：

| 输入 | 结果 |
|---|---|
| `1` → `admin` → `123456` | 登录成功，身份 ADMIN，打印四项管理权限 |
| `1` → `student` → `123456` | 登录成功，身份 STUDENT，打印查询与预约权限 |
| `1` → `admin` → `111111` | 提示"账号或密码错误"，退回菜单 |
| `1` → 空回车 → 空回车 | 提示"账号和密码都不能为空" |
| `9` | 提示"请输入 1 或 0" |

退出码都是 0，中文没有乱码。
