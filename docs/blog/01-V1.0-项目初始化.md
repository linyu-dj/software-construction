# V1.0 项目初始化：工程骨架与包结构的建立

> 软件构造综合实践 · 第 1 轮迭代
> 提交 `5e92c91` · 标签 `v1.0` · 2026-11-12

本轮功能只有登录，但确定的是工程骨架：包结构、入口形式、角色概念。这三项如果在首轮定得不当，后续十九轮都要额外补偿。

## 一、包结构：为什么用 campus 而不是默认包

系统后面要长出实体、服务、数据访问三层，根包必须能挂住它们。`campus` 对应题目（校园资源预约），`campus.entity`、`campus.service`、`campus.dao` 顺着排下去即可。

如果本轮图省事用默认包，等到 V1.2 建 `User` 实体时还得改一次包，同样的工作做两遍。

## 二、入口与角色

所有交互从 `SystemMain.main()` 进入。这个入口在后续版本里一直保留，只是它调用的东西会越来越多。

角色判断放在本轮有实际原因：管理员和学生的权限完全不同，V2.0 做资源管理要按角色分菜单。本轮只做登录也必须能说清"当前是谁"，否则下一轮没有可用的状态。

## 三、代码形态：这里故意保留了耦合

账号直接写在主方法里：

```java
String adminUsername = "admin";
String adminPassword = "123456";
String studentUsername = "student";
String studentPassword = "123456";
```

判断和打印挤在同一个 if-else：

```java
if (username.equals(adminUsername) && password.equals(adminPassword)) {
    System.out.println("登录成功！欢迎您，管理员 " + username + "。");
    System.out.println("当前身份：ADMIN");
    loggedIn = true;
} else if (username.equals(studentUsername) && password.equals(studentPassword)) {
    ...
} else {
    System.out.println("登录失败：账号或密码错误，请重新输入。");
}
```

任务书明确要求本阶段代码全部写在主类、不抽工具类。这条要求初看有点反直觉，实际是给后面几轮留改造动因：如果第一轮就把校验、打印、登录拆开，后续所谓的重构就没有真实起点，迭代记录也会失真。现在这段代码确实难扩展，V1.1 要加注册功能就只能动它，这正是本轮想要的状态。

## 四、输入处理上的取舍

菜单、账号、密码三个输入统一用 `nextLine().trim()`，没有用 `nextInt()`。

原因是 `nextInt()` 只消费数字，回车符留在缓冲区，紧接着的 `nextLine()` 会读到空串，用户遇到的现象就是"刚输完账号，直接跳到了密码"。代价是菜单选项要写成 `"1".equals(choice)` 而不是 `choice == 1`。用字符串比较换掉整个交互里吞输入的可能，这笔账划算。

## 五、踩过的坑

**1. `javac: 找不到目录: out`**

首次编译直接失败。`-d out` 只指定输出目录，`javac` 不会创建它，需要先 `mkdir out`。这条已经在 `run.bat` 里处理掉了。

**2. 中文全部乱码**

源码是 UTF-8，Windows 上的 `javac` 默认按 GBK 读源码，编译出来的字符串本身就是错的，调控制台没有用。三处要同时设：编译加 `-encoding UTF-8`，运行加 `-Dfile.encoding=UTF-8`，批处理再加 `chcp 65001`。

**3. Pages 上的博客链接 404**

首页写好了，点进去却是 GitHub 的 Unicorn 页面。原因是 Jekyll 把 `01-V1.0-项目初始化.md` 渲染成 `.html`，索引里写的 `.md` 在站点上不存在。把 `docs/index.md` 的链接后缀统一改成 `.html` 后恢复正常，以后每加一篇都要守这条。

**4. IDEA 提示"未安装 Git"**

这条与代码无关。两个原因叠加：IDEA 没有配置 Git 可执行路径（配置目录里没有 `git.xml`），并且新打开的目录默认处于未信任状态，未信任时 Git 命令被禁用。系统里的 Git（2.45.1）正常，命令行提交推送不受影响，IDEA 侧需要手动配一次路径、点一次信任。

## 六、验收

五组输入，实际输出：

| 输入 | 结果 |
|---|---|
| `1` → `admin` → `123456` | 登录成功，身份 ADMIN，打印四项管理权限 |
| `1` → `student` → `123456` | 登录成功，身份 STUDENT，打印查询与预约权限 |
| `1` → `admin` → `111111` | 账号或密码错误，退回菜单 |
| `1` → 空回车 → 空回车 | 账号和密码不能为空 |
| `9` | 请输入 1 或 0 |

退出码均为 0，中文无乱码。
