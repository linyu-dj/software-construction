# Task01 · V1.0 项目初始化

## 本任务目标

搭建项目基础结构，实现程序入口 `SystemMain` 与身份登录，做出最基础的可运行版本。

## 目录结构

```
Task01-V1.0-项目初始化/
├─ src/
│  └─ campus/
│     └─ SystemMain.java     唯一主类，本阶段全部逻辑都在这里
└─ run.bat                   命令行一键编译 + 运行（可选，IDEA 里直接 Run 也行）
```

## 固定测试账号

| 角色 | 账号 | 密码 |
|---|---|---|
| 管理员 ADMIN | `admin` | `123456` |
| 学生 STUDENT | `student` | `123456` |

## 运行方式

**方式一：IDEA**

1. `File → Open` 选择本文件夹 `Task01-V1.0-项目初始化`
2. `File → Project Structure → Project SDK` 选 **JDK 1.8**
3. 右键 `src` → `Mark Directory as → Sources Root`
4. 打开 `SystemMain.java`，点 `main` 方法左侧绿色三角运行

**方式二：命令行**

```powershell
cd "Task01-V1.0-项目初始化"
.\run.bat
```

## 验收用例

| 用例 | 输入 | 预期输出 |

| 管理员登录 | `1` → `admin` → `123456` | 欢迎您，管理员 admin，身份 ADMIN |

| 退出 | `0` | 已退出系统，再见 |
