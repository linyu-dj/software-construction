# 软件构造综合实践 · 校园资源预约系统

> 课程：软件构造综合实践
> 开发模式：20 阶增量迭代（所有版本基于上一版本增量开发，禁止推倒重写）
> 核心架构思想：业务与视图完全解耦
> 考核基线：控制台版本为必做满分项

## 技术栈

| 项目 | 说明 |
|---|---|
| JDK | JDK 8（1.8.0_451），Language Level 8 |
| 第三方框架 | 无。纯原生 Java（集合、IO、Stream、反射、注解、线程池） |
| 持久化 | 文本文件（user.txt / resource.txt / reserve.txt / operation_log.txt） |
| IDE | IntelliJ IDEA 2026.1.4，每个任务一个独立 Project |

## 提交与版本规范

- 分支：`main` 为交付分支，实验性改动走 `feat/xxx` 分支
- 每完成一个任务：一次 commit + 一个 tag（`v1.0` ~ `v6.0`）+ 一篇博客
- 提交信息格式：`feat(V1.1): 实现用户注册与账号查重`
- 严禁：推倒重写、复制拼凑、修改 entity/service/dao/exception/utils 核心代码做拓展

## 快速开始

```bash
git clone https://gitee.com/<你的用户名>/software-construction.git
cd software-construction/Task01-V1.0-项目初始化
```

用 IDEA 打开该任务文件夹 → 等待自动索引 → 运行 `SystemMain`。
